# Kanchana Sadaruwan Education Website

A responsive, image-rich, trilingual (Sinhala / English / Tamil) education website for Grades 1–11.

## First website build
- Modern responsive homepage with education photography and blue / purple visual styling
- Mathematics, Science and English subject sections
- Grade 1–11 class section
- Learning resources overview: timetable, exam results, past papers, notices, video lessons and PDFs
- Student login and teacher/admin login interface
- Student registration-interest form with parent contact field
- WhatsApp contact shortcut
- Mobile-friendly layout

## Important implementation status
This commit is the **front-end design preview**, not the completed tuition management system. Login forms are not connected to authentication, and the registration form does not transmit or store personal data. Student marks, parent phone numbers, attendance, payments, income reports and teacher uploads must be protected by a secure backend/database and role-based access before they are enabled.

The teacher's real WhatsApp number, class times, fees, teacher profile photo and actual notices/resources still need to be supplied and configured.

## Netlify deployment
This is a static front-end starter. Import this repository into Netlify and set the publish directory to the repository root.
